# Datos de sondeos del Observatorio 29N

Lee tres veces al día la tabla de estimación de voto de [Wikipedia](https://en.wikipedia.org/wiki/Opinion_polling_for_the_2026_Spanish_general_election) y publica `data/sondeos.json`.

Los datos proceden de Wikipedia y se distribuyen bajo licencia CC BY-SA 4.0.

Si la tabla cambia de forma o aparecen valores imposibles, la tarea falla y se conserva el último archivo bueno. Del 24 de noviembre al 29 de noviembre a las 20:00 (hora de Madrid) el archivo queda vacío por el artículo 69.7 de la LOREG.
